## 📌 Overview
**Markan** is a smart parking solution engineered to alleviate campus parking congestion at IMSIU. By integrating IoT magnetic sensors, real-time cloud data, and an intuitive mobile interface, Markan significantly cuts down search times and optimizes traffic flow.

---

## 📊 Key Insights & Problem Statement
Based on our campus surveys and gap analysis:
* **82.3%** of respondents spend **5 to 20 minutes** daily searching for parking.
* **42.2%** reported arriving late to classes/meetings due to congestion.
* High interest (**97%**) in a mobile solution offering real-time spot navigation.

---

## 🛠 System Architecture & IoT Flow
1. **Sensors:** Surface-mounted geomagnetic sensors detect vehicle presence.
2. **Gateway:** Transmits occupancy status via LoRaWAN / Cellular.
3. **Cloud & App:** Updates real-time availability on the Markan mobile app with live navigation and reservation options.
